# Roadmap

Varje milestone: planera → implementera → validera → testa → dokumentera. Sedan
stopp och sammanfattning innan nästa milestone påbörjas.

| Milestone | Innehåll | Status |
|---|---|---|
| M0 | Kravanalys, arkitektur, datamodell, RLS-strategi, risker | **Väntar på godkännande** |
| M1 | Foundation – se [MILESTONE_1_FOUNDATION.md](MILESTONE_1_FOUNDATION.md) | Planerad |
| M2 | Inloggning (Apple/Google), onboarding, hushåll och barn i UI, radering av konto, staging | – |
| M3 | Ekonomi 1: konton, transaktioner, kategorier, synlighet | – |
| M4 | Ekonomi 2: budgetperioder, rollover, inkomster, fasta kostnader | – |
| M5 | Sparmål och veckopeng | – |
| M6 | Kalender och barns aktiviteter | – |
| M7 | Uppgifter och rutiner | – |
| M8 | Barnläge (separat UI) | – |
| M9 | Pushnotiser | – |
| M10 | Familjepuls (regelbaserad) | – |
| M11 | Abonnemang, juridik, butiksberedskap, lansering | – |
| Senare | CSV-import, Enable Banking, Facebook/Microsoft | – |

Ordningen för M3–M8 bestäms efter M1 (OPEN_QUESTIONS Q4).
